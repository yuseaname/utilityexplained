## 2. S-rank formula (per article)

- **Primary keyword = the question** (dossier §4); head term only as secondary. Title ≤60 chars containing the question.
- **Quick Answer** = 40–60 word featured-snippet bait (bold verdict + cited fact + anti-hype second para — house style).
- **FAQ** = 3 `{{< faq >}}` blocks (JSON-LD auto-emitted site-wide).
- **Sources**: 4–8 real citations with `(retrieved 2026-08-30)` — Commander gathers EIA/DOE/EPA/manufacturer facts BEFORE drafting; every number in the draft traces to a source. Zero invented figures.
- **Internal links**: 2–4 out per article + a final surgical wave adding inbound links from existing articles per the dossier's anchor map (03/05/11/gadgets→#1; 07→#2/#5; 13/47→#3; 44/06→#4) — 1–2 line-level edits per existing article, nothing else touched.
- **Length**: 1,400–2,100 words (house band). Author personas rotated (Chen/Mendoza/Harrington).
- **Affiliate wiring**: 2 `{{< product-box >}}` per article placed late (house law), ASIN row in comparison tables where natural, disclosure shortcode on open. **Every ASIN re-verified against a live Amazon page at wiring time** (dossier §7.3 — publish-gate applies since ship date is yours).

## 4. Image pipeline (magica / GPT Image 2 only)

- Model `gpt-image-2-text`, `quality:"medium"`, heroes and in-body at `1536x1024` (~0.041 credits each). **Balance check first.** Budget: ~25 article images (5/article avg) + ~4 product illustrations ≈ **29 runs ≈ 1.3 credits total**.
- Style: "The Independent Bill Auditor" bible — flat ledger paper `#fffcfa`, faint grid-teal `#3c655c` scaffolding, deep ink `#0e201c`, mono numerals, **amber `#e8a33d` on exactly one element per image**, no gradients/photo texture. Short labels only (no pseudo-sentences — the SQ-056 hard rule that got images pulled).
- Heroes: scene-style, **no text/logos/watermarks**. In-body: concept diagrams via `{{< visual src alt wide >}}`, descriptive sentence alts; product-style alts start with "Illustrative".
- Naming: `{slug}/{slug}_hero_v2.webp` + `{concept}.webp`; PNG→WebP conversion locally; register ASIN visuals in `data/product_images.yaml` with width/height.
- Per-article image briefs (placement, concept, purpose, filename, alt intent) authored before generation — nothing decorative.
