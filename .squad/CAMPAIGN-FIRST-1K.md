# CAMPAIGN FIRST-$1K — Squad Execution Plan
**Commander draft · 2026-08-29 · Objective: first $1,000 affiliate revenue via the winter 2026/27 window, top-earner trajectory after.**

- 85 published articles: 33 thin (<1,000w), 33 mid, 19 strong; 4 thin drafts
- **The money cluster is the thinnest cluster**: 45-generator (411w), 42-space-heater (471w), 48-heat-pump (467w), 47-DIY-leaks (435w), ductless-vs-central (571w) — all buying-decision pages at stub depth

- Trust layer complete (authors, editorial policy, corrections, disclosure); visual layer complete (SQ-058)

## 1. Campaign law

1. **Revenue orders work.** Every packet must state which blocker it moves: traffic, conversion, or EPC. No polish missions until the winter window closes.
2. **Facts frozen = facts verified.** All expansion claims go through the SQ-051..054 evidence gate (verified sources or cut). No invented tariffs/prices/numbers.
3. **Crisis pages stay clean.** 21-past-due (and hardship sections) never carry a box. Fit adjudication is per-page, TWIN Q verdict + Commander sign-off.
4. **Mechanical gates, every mission:** `hugo --minify --gc` EXIT 0 → `scripts/check_image_paths.py .` → `verify-links` → evidence-fabrication guard (action log, not prose) → commit on user go.
5. **Secrets doctrine.** No keys in packets; any image generation stays Commander-executed via Magica (gpt-image-2 only).
6. **Flash-only cost policy** holds; Ray/Evo X2 stay ON-CALL.

## 2. Mission ladder

### SQ-060 — Fix the instrument (small, first)
**Goal:** repair the Rybbit over-firing so KPIs are real.
**Seats:** Executor (repo fix) + Scout (reproduce/count) + Lieutenant review.
**Exit:** single page-view per page-load verified across devices; baseline snapshot re-taken; `sessions/day` becomes the campaign KPI.

### SQ-061 — Money-Five deepening (the core mission)
**Goal:** take the five commercial stubs to 1,200–1,600w, evidence-gated, each with the product box(es) it merits.
**Pages:** 45-generator-vs-portable · 42-space-heater · 48-heat-pump-vs-furnace · 47-DIY-energy-leaks · ductless-mini-split-vs-central.
**Formation:** 5-seat dsv4 SWARM WING (map-reduce: one page per seat, implement preset) → Scout fact-checks every sourced claim → Lieutenant (multi-turn strength) restructures for rank+convert → **TWIN Q blind verdict per page**: "would this rank on Bing and convert to an Amazon click? verdict + 3 fixes" → Executor final write + gates.
**Product scope:** extend verified inventory ONLY (Kill A Watt B00009MDBU, Emporia B0C7B1LKDW, Kasa B08LN3C7WK…); new ASINs require Commander-verified spec sheets first. Generators/transfer switches = new territory → Lieutenant research packet before any box.
**Exit:** all five ≥1,200w, ≥1 box each (where defensible), TWIN Q verdict ≥ "ship with minor fixes", all gates green, committed.
**Why first:** highest $/word on the site; winter demand ~10 weeks out.

### SQ-062 — Winner monetization (parallel with 061)
**Goal:** honest boxes on proven-traffic pages that currently earn nothing.
**Targets (from Rybbit):** water-meter-running · water-meter-leak-indicator · 30-sudden-spike · how-to-read-a-water-meter · 02-average-utility-costs (adjacent).
**Formation:** Scout compiles per-page context → Lieutenant drafts fit cases → **TWIN Q adjudicates each fit (allow/reject + reason)** → Executor wires only ALLOW verdicts → gates.
**Hard rules:** dye-test/leak pages get dye tablets + leak-monitor fits only; no box where the reader is in distress; max 1 box per informational page.
**Exit:** +4–6 boxes on traffic pages, zero fit-rejects overridden, gates green.

### SQ-063 — Lattice completion
**Goal:** kill orphan status; 2–3 inbound links to every thin page from hubs/siblings (contextual, not footer spam).
**Formation:** Scout builds the full inbound-link matrix → wing seats propose placements page-by-page (map-reduce) → Executor writes → `verify-links` + matrix re-count.
**Exit:** 0 pages with 0 inbound; thin tier ≥2 each; no link stuffed beyond 8/page.

### SQ-064 — Fee-stub deepening waves (filler between money work)
**Goal:** lift the ~15 highest-value definitional stubs (27-connection, 17-customer-charge, 24-delivery-vs-supply, 18-fuel-adjustment, 22-minimum-bill, 20-proration, 49-demand…) to 800–1,100w **only where traffic or hub adjacency justifies it.** Sequence by Rybbit + lattice position, not by number order.
**Formation:** one wave = 5 wing seats; Lieutenant verify pass; gates.
**Exit per wave:** pages gain tables/examples (already have visuals from SQ-058); no new images needed.

### SQ-065 — Winter readiness sprint (calendar-gated: complete by Oct 15)
**Goal:** capture seasonal demand. Year-stamp refreshes ("2026/2027"), FAQ schema already in place; internal promos from high-traffic pages into the Money-Five; GSC submission push if Search Console access exists (user action).
**Formation:** Scout stale-year audit → Executor fixes → gates.

### SQ-066 — Program diversification (month 3+, user-gated)
**Goal:** apply to energy-plan / solar-lead affiliate programs; wire heat-pump + net-metering pages as funnels (these out-earn Amazon per conversion).
**User actions first:** applications + account approvals. Squad prepares funnel pages + disclosure updates only after approval.
