# Quality Gate System
## UtilityExplained.com — Content Production Standards

## Pre-Publication Checklist

### 1. Factual Accuracy (Required)
- All technical terms (kWh, therm, CCF) correctly defined
- Calculations and formulas mathematically correct
- Statistics cite reasonable sources (EIA, utility data)
- No claims of "average" without context
- Dollar amounts specify time period
- No overpromising on savings (use ranges)

### 2. Internal Linking (Minimum 3-5)
- Link to relevant pillar article (at least 1)
- Link to related cluster articles (at least 2)
- No broken links
- Descriptive anchor text
- Links add value

### 3. SEO Meta Requirements
- Title tag: 50-60 characters, includes keyword
- Meta description: 150-160 characters
- Keyword in: H1, first 100 words, at least one H2, URL slug
- Keyword density: 1-2% (natural)

### 4. Image Requirements (1-2 per article)
- At least one custom image or graphic
- All images have descriptive alt text
- Image file size < 200KB
- Tables used for data comparisons

### 5. FAQ Section (Required for >800 words)
- 3-5 FAQs using real questions from PAA research
- Structured with proper schema markup

### 6. Frontmatter Validity
- All required fields present
- Date in ISO format (YYYY-MM-DD)
- Categories match approved list
- Featured image path valid

## Brand Voice Requirements

### Tone and Style
- Plain English first, jargon explained second
- Use "you" and "your" (conversational)
- Explain technical terms immediately after first use
- Short paragraphs (2-4 sentences max)
- Never condescending

### Reassuring Tone
- Acknowledge utility bills ARE confusing
- Validate frustration
- Emphasize reader is not alone
- Focus on empowerment

### Data-Rich Approach
- Use tables for comparisons
- Include concrete numbers and ranges
- Show calculations where helpful

## Scoring Rubric

**Minimum score to publish: 7.0 average**

1. **Accuracy (Weight: 2.0)** - Perfect technical accuracy earns 10
2. **Depth (Weight: 1.5)** - Comprehensive coverage earns 10
3. **Readability (Weight: 1.5)** - Flows perfectly earns 10
4. **SEO (Weight: 1.0)** - Perfect optimization earns 10
5. **Internal Linking (Weight: 1.0)** - 5+ strategic links earns 10
6. **Visual Elements (Weight: 0.5)** - Multiple custom graphics earns 10
7. **FAQ Section (Weight: 0.5)** - 5+ excellent FAQs earns 10

## Final Pre-Publication Verification

Before hitting "Publish":
- Article scores 7.0+ on rubric
- All checklist items passed
- Technical build succeeds (no Hugo errors)
- Preview viewed on desktop and mobile
- All links tested and working
